# Rainwater Ripple Watch

Podemos criar para integrar esse sistema de aproveitamento de água da chuva do Arduino Uno do arquivo anexado. USB direto pelo navegador — crie a aplicação com Web Serial API para acompanhar as leituras do Arduino pelo computador.
